# Rusting Newsletter Sources

This directory is separate from the development chronicle. Cycle records
capture evidence continuously; newsletter documents synthesize that evidence
for a public audience at Era boundaries.

An Era post remains here from draft through publication. Update its status and
canonical URL instead of copying it between folders. Reuse linked media from the
Era's devlog directory rather than duplicating binaries.

Every technical claim should link to a tagged source revision, reproducible
scenario and seed, or an explicitly identified qualitative observation.
