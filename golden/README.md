# Golden Runs

This directory contains deliberately selected deterministic output used for
regression tests and public explanations. Full exploratory runs belong in the
ignored `runs/` directory.

Golden material must remain compact, reproducible from a documented command,
and free of timestamps, machine-specific paths, or private information.

ANSI-free terminal screens are presentation contracts as well as review
artifacts. Their scenario, seed, duration, dimensions, view, and any stable
focus identity must be documented beside them.
